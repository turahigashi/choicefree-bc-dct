## Intentionally excluded file categories

- `Scratch*`: temporary proof-search and experiment files
- `*_iteration*` outside the listed public closure: development staging files not imported by the audited public roots
- `old*`, `backup*`, `*.bak`: historical backups and failed routes
- unfinished-proof files and files containing open experimental statements: not part of the verified public theorem closure
- `BishopSec5_Measure.lean`, `BishopSec6_Product.lean`, `BishopSec7_LocallyCompact.lean` outside the closure: later-section or legacy modules not needed by the public DCT aliases
- `.lake/`, `.git/`, `.olean`, `.ilean`, cache and editor files: build products or local metadata, not source artifact files

## Notes on historical iteration files

The implementation modules under `Mathdemo/Internal/` are grouped by the layer they build (`Rat/`, `Real/`, `Measure/`, `Sec4/`); the public presented-real DCT development imports declarations from them transitively.  Where a module only supplied non-public classical audit bookkeeping, the artifact keeps a compatibility node or an inert type name and documents the reason in comments.
